# Add WhatsApp to Social Media Platforms

## Summary
Add WhatsApp as a selectable social media platform in the admin UI, matching the existing pattern for Facebook, Instagram, etc. The colored icon already exists in `SocialIcons.tsx` — we need to add a white variant and wire it into all icon maps across the app.

## Changes (6 files)

### 1. `resources/js/components/ui/SocialIconsWhite.tsx`
- Add `WhatsAppWhiteIcon` (white fill, same SVG path as colored version)

### 2. `resources/js/pages/admin/site-settings/AdminSiteSettingsSocial.tsx`
- Import `WhatsAppIcon` from `SocialIcons`
- Add `{ label: 'WhatsApp', placeholder: 'https://wa.me/...', icon: WhatsAppIcon }` to `SOCIAL_PLATFORMS` array

### 3. `resources/js/components/layout/Navbar.tsx`
- Import `WhatsAppWhiteIcon` from `SocialIconsWhite`
- Add `whatsapp: WhatsAppWhiteIcon` to `SOCIAL_ICONS` map (line 36)

### 4. `resources/js/components/layout/Footer.tsx`
- Import `WhatsAppIcon` from `SocialIcons`
- Add `whatsapp: WhatsAppIcon` to `brandIcons` map inside `resolveSocialIcon()` (line 50)

### 5. `resources/js/components/layout/SocialSidebar.tsx`
- Import `WhatsAppIcon` from `SocialIcons`
- Add `whatsapp: WhatsAppIcon` to `brandIcons` map (line 12)

### 6. `resources/js/pages/general/Contact.tsx`
- Import `WhatsAppIcon` from `SocialIcons`
- Add `whatsapp: WhatsAppIcon` to `brandIcons` map inside `getSocialIcon()` (line 99)

## No changes needed
- Seeder files — WhatsApp URL is configured by admin via the UI
- Database/model — social_links is already a JSON array, supports any label
- TypeScript types — already accept any `{ label: string; href: string }`
