# Plan: Add Loading Spinners to All Admin Save Buttons

## Problem
When saving on admin pages — especially when uploading large files like videos — there's no visual feedback. Users keep clicking because they don't know if the save is in progress.

## Current State

- **EntityFormDialog** (`components/forms/EntityFormDialog.tsx`) already shows a `<Loader2>` spinner and disables buttons when `isSubmitting` is true. All 15+ CRUD pages using this dialog (Visas, Tours main save, Team, Promos, Partners, Hotels, Gallery, Flights, Events, Destinations, Deals, Blog, Cars, Bookings, Complaints) are fine.

## Approach

For each file, the change is mechanical and identical:

1. Add `const [isSaving, setIsSaving] = useState(false);` at component top
2. Wrap the async save function body: set `setIsSaving(true)` before the API call, and `setIsSaving(false)` in a `finally` block
3. Update the save `<Button>` to:
   - Show `<Loader2 className="mr-1 h-4 w-4 animate-spin" />` when `isSaving` is true
   - Set `disabled={isSaving}`
   - Add `Loader2` to the lucide-react import

The pattern for each file:
```tsx
const [isSaving, setIsSaving] = useState(false);

const save = async () => {
    setIsSaving(true);
    try {
        // ... existing logic ...
    } catch {
        // ... existing error handling ...
    } finally {
        setIsSaving(false);
    }
};

// Button change:
<Button size="sm" onClick={save} disabled={isSaving}>
    {isSaving ? <Loader2 className="mr-1 h-4 w-4 animate-spin" /> : <Save className="mr-1 h-4 w-4" />}
    {t('admin.settings.save')}
</Button>
```

For **AdminUsers.tsx** `UserEditDialog`: pass `updateMutation.isPending` as a prop to the dialog and disable the submit button + show spinner when pending.
