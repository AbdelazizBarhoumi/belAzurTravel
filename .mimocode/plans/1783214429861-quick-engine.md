# Fix: Public pages calling admin category-types API (401 Unauthorized)

## Root Cause

`resources/js/components/layout/Navbar.tsx` (line 20) imports `useCategoryTypes` from `@/hooks/useCategoryTypes`, which calls `/api/admin/category-types?type=...` — an endpoint requiring authentication. Since the Navbar renders on every public page, all visitors trigger 6 unauthorized API calls for each entity type (destinations, hotels, tours, cars, events, deals).

## Fix

**File:** `resources/js/components/layout/Navbar.tsx`

1. Replace the admin import:
   ```
   // Before (line 20):
   import { useCategoryTypes, type CategoryType } from '@/hooks/useCategoryTypes';
   
   // After:
   import { useCategoryTypesPublic, type PublicCategoryType } from '@/hooks/usePublicData';
   ```

2. Replace the 6 hook calls (lines 590-595):
   ```
   // Before:
   const { data: destinationCategoryTypes = [] } = useCategoryTypes('destinations');
   const { data: hotelCategoryTypes = [] } = useCategoryTypes('hotels');
   const { data: tourCategoryTypes = [] } = useCategoryTypes('tours');
   const { data: carCategoryTypes = [] } = useCategoryTypes('cars');
   const { data: eventCategoryTypes = [] } = useCategoryTypes('events');
   const { data: dealCategoryTypes = [] } = useCategoryTypes('deals');
   
   // After:
   const { data: destinationCategoryTypes = [] } = useCategoryTypesPublic('destinations');
   const { data: hotelCategoryTypes = [] } = useCategoryTypesPublic('hotels');
   const { data: tourCategoryTypes = [] } = useCategoryTypesPublic('tours');
   const { data: carCategoryTypes = [] } = useCategoryTypesPublic('cars');
   const { data: eventCategoryTypes = [] } = useCategoryTypesPublic('events');
   const { data: dealCategoryTypes = [] } = useCategoryTypesPublic('deals');
   ```

3. Update all `CategoryType` type references to `PublicCategoryType` throughout the file (lines 209, 218, 447, 453, 672, 708). The public type is structurally compatible — it uses `Record<string, string>` for `label`/`name` instead of `{ en, fr, ar }`, which is a superset.

## Why this works

The public hook (`useCategoryTypesPublic`) calls `/api/categories/types?entity_type=...` — an unauthenticated endpoint that returns the same data structure. The admin pages under `resources/js/pages/admin/` continue using the admin hook unchanged.
