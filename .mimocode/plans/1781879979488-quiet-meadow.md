# Landing Video Modal — Implementation Plan

## Overview
Add a video modal that opens automatically on the landing page, with the video uploaded by the admin from the Site Settings page. Store the video path in the existing `content` JSON column (no migration needed).

---

## Step 1: Backend — Accept video upload in `SiteSettingsController::update()`

**File:** `app/Http/Controllers/Api/SiteSettingsController.php`

- Add validation rule: `'video' => ['nullable', 'file', 'mimes:mp4,webm,mov', 'max:51200']`
- In the `update()` method, after building `$content`, handle the video file:
  ```php
  if ($request->hasFile('video')) {
      // Delete old video if exists
      $oldVideo = $content['landing_video']['url'] ?? null;
      if ($oldVideo) {
          $oldPath = str_replace('/storage/', '', $oldVideo);
          \Illuminate\Support\Facades\Storage::disk('public')->delete($oldPath);
      }
      $path = $request->file('video')->store('uploads/site', 'public');
      $content['landing_video'] = ['url' => '/storage/' . $path];
  }
  ```
- When request is JSON (no file), keep existing `landing_video` in content as-is

## Step 4: Landing Video Modal Component (NEW FILE)

**File:** `resources/js/components/sections/LandingVideoModal.tsx`

- Uses `useSiteSettingsContext()` to get `settings.landingVideo?.url`
- Checks `localStorage` key `landing_video_dismissed` on mount
- If not dismissed and video URL exists, opens modal after 1.5s delay
- Uses existing `Dialog`/`DialogContent` from `@/components/ui/dialog`
- Custom styling: `max-w-3xl`, transparent background, video with controls
- On close: sets `localStorage.setItem('landing_video_dismissed', '1')`
- Close triggers: click outside (Radix Dialog default), X button
