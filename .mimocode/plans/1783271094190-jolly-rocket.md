# Plan: Replace Manual SVG Textarea with Iconify Icon Picker

## Context

The hotel admin form has an amenity icon editor where users can choose "Custom SVG" and paste raw SVG markup into a plain `<Textarea>`. This is bad UX for non-technical users. The goal is to install `@iconify/react` and build a searchable icon picker so users can search and select from 200,000+ icons instead of writing SVG code manually.

## Package

**Install `@iconify/react`** — official React component, TypeScript-first, auto-fetches icon data via API (no bundled icon sets needed).

## Files to Create

### 1. `resources/js/components/ui/IconPicker.tsx` (NEW)

A searchable icon picker using existing shadcn/ui primitives:
- **Popover** (trigger) + **Command** (cmdk, already installed) for the dropdown
- Search input calls Iconify API: `https://api.iconify.design/search?query={q}&limit=40`
- Results displayed as a CSS grid (4 columns) of clickable `<Icon>` previews
- Selected icon stored as Iconify name (e.g., `"mdi:wifi"`)
- Props: `value: string`, `onChange: (value: string) => void`, `placeholder?: string`
- Debounced search (300ms)

## Data Model

| iconType | icon value format | Example |
|----------|------------------|---------|
| `predefined` | simple string key | `"wifi"` |
| `iconify` | `prefix:name` | `"mdi:wifi"` |
| `custom` | raw SVG string | `"<svg>...</svg>"` |

Detection at render time: starts with `<svg` → custom SVG; contains `:` → iconify; otherwise → predefined.
