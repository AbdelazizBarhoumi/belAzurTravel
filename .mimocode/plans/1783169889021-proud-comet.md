# Plan: Fix Dropdown Disappearing When Hovering Between Items

## Problem
When a header dropdown has items with sub-dropdowns AND normal items:
1. Hover over an item with sub-dropdown → sub-dropdown appears
2. Move to a normal item (no sub-dropdown) → entire header dropdown disappears

## Root Cause
In `DesktopFlyoutItems` (line 86-99), the `onMouseEnter` handler only calls `hover.clear()` when `hasChildren` is true. When moving to a normal item without children, the scheduled close from the previous item is NOT cancelled, so the dropdown closes.

```jsx
onMouseEnter={() => {
    if (hasChildren) {  // <-- Only clears for items WITH children
        hover.clear();
        setHoveredPath(itemPath);
    }
}}
```

## Fix
Always call `hover.clear()` in `onMouseEnter`, regardless of `hasChildren`. This cancels any scheduled close when moving to any sibling item.

## File to Modify
`resources/js/components/layout/Navbar.tsx`

## Change (line 89-93)
```tsx
// Before
onMouseEnter={() => {
    if (hasChildren) {
        hover.clear();
        setHoveredPath(itemPath);
    }
}}

// After
onMouseEnter={() => {
    hover.clear();
    if (hasChildren) {
        setHoveredPath(itemPath);
    }
}}
```

4. Move to normal item → header dropdown should stay open
