# E-Payment Integration (ClictoPay)

## Overview

Integrate ClictoPay (Tunisian e-payment gateway) into the booking flow. Customers pay at booking time via ClictoPay's hosted payment page. The system verifies payment status and auto-confirms bookings on success.

## Payment Flow

```
Customer clicks "Book Now" → Booking created (Pending) → Backend calls ClictoPay /register.do
→ Customer redirected to ClictoPay payment page → Enters card details
→ ClictoPay redirects back to our /payment/callback?orderId=xxx
→ Backend verifies via /getOrderStatus.do → Updates booking to "Confirmed" + records Payment
```

## ClictoPay API Reference

- **Sandbox**: `https://test.clictopay.com/payment/rest`
- **Production**: `https://ipay.clictopay.com/payment/rest`
- **Initiate**: `POST /register.do` (userName, password, orderNumber, amount in milliemes, currency=788 for TND, returnUrl, language)
- **Verify**: `GET /getOrderStatus.do` (orderId, userName, password)
- **Amount**: Stored in milliemes (1 TND = 1000 milliemes). E.g., 150.50 TND = 150500

### 3. Service: `app/Services/ClictoPayService.php`

Encapsulates all ClictoPay API interactions:

- `createPayment(Booking $booking): array` — calls `/register.do`, returns `{orderId, formUrl}`
- `verifyPayment(string $orderId): array` — calls `/getOrderStatus.do`, returns status + amount
- `getOrderStatus(int $orderStatus): string` — maps numeric status to label (0=declined, etc.)

### 4. Migration: `database/migrations/2026_06_22_100000_add_clictopay_fields_to_payments_table.php`

```

```

### 5. Update Payment model: `app/Models/Payment.php`

Add `clictopay_order_id` to `$fillable`.

### 6. Update Booking model: `app/Models/Booking.php`

Add `payment()` → HasOne Payment relationship.

### 7. Controller: `app/Http/Controllers/Api/PaymentController.php`

| Method | Endpoint | Description |
|--------|----------|-------------|
| `initiate` | `POST /api/bookings/{id}/pay` | Creates ClictoPay session, returns `formUrl` for redirect |
| `callback` | `GET /api/payment/callback` | Handles ClictoPay return, verifies payment, updates booking |

**`initiate` flow:**
1. Verify booking belongs to user and is `Pending`
2. Call `ClictoPayService::createPayment($booking)`
3. Create Payment record with `status='pending'`, `clictopay_order_id`
4. Return `{ formUrl }` to frontend

**`callback` flow:**
1. Receive `orderId` from query params
2. Call `ClictoPayService::verifyPayment($orderId)`
3. If payment successful (OrderStatus indicates success):
   - Update Payment: `status='paid'`, `paid_at=now()`, `reference=$orderId`
   - Update Booking: `status='Confirmed'`, `confirmed_at=now()`
   - Notify admin + client
4. Redirect to `/client/dashboard?payment=success` or `?payment=failed`

### 8. Routes: `routes/api.php`

```php
// Payment
Route::post('/bookings/{id}/pay', [PaymentController::class, 'initiate']);
Route::get('/payment/callback', [PaymentController::class, 'callback']);
```
