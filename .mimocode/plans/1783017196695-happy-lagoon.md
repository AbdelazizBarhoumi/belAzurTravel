# Plan: Dynamic Visa CRUD Management

## Overview
Add a "Visa" section to the admin sidebar with full CRUD (create, read, update, delete) for visa countries. Replace the hardcoded `COUNTRIES` array in the public visa page with database-backed data.

---

## 1. Database Migration

**Create:** `database/migrations/2026_07_02_000000_create_visas_table.php`

```
visas table:
- id (auto-increment)
- code (string, unique) — ISO 2-letter country code, e.g. "FR"
- name (string) — display name, e.g. "France"
- flag (string) — emoji flag, e.g. "🇫🇷"
- region (string) — region group, e.g. "Europe"
- processing (string) — processing time, e.g. "10-15 jours"
- price (unsignedInteger) — price in DT
- is_active (boolean, default: true) — admin can toggle visibility
- sort_order (unsignedInteger, default: 0) — for ordering
- timestamps
```

---

## 2. Backend: Model

**Create:** `app/Models/Visa.php`

- `$fillable`: `['code', 'name', 'flag', 'region', 'processing', 'price', 'is_active', 'sort_order']`
- No localized fields needed — visa names are country names, not translatable content

---

## 3. Backend: Admin Controller

**Create:** `app/Http/Controllers/Api/AdminVisaController.php`

Follow the `AdminTeamController` pattern:
- `index()` — return all visas, cached 5 min
- `store(Request $request)` — validate + create
- `show($id)` — findOrFail + return
- `update(Request $request, $id)` — validate + update
- `destroy($id)` — delete
- Validation rules: `code` required|string|max:2, `name` required|string, `flag` required|string, `region` required|string, `processing` required|string, `price` required|integer|min:0, `is_active` boolean, `sort_order` integer

---

## 4. Backend: Public Controller

**Create:** `app/Http/Controllers/Api/VisaController.php`

- `index()` — return active visas ordered by sort_order, cached 3 min
- Public endpoint, no auth required

---

## 5. Backend: Routes

**Edit:** `routes/api.php`

Add imports for `AdminVisaController` and `VisaController`.

Add in the public section (near other public GET routes):
```php
Route::get('/visas', [VisaController::class, 'index']);
```

Add in the `role:admin` group:
```php
Route::get('/admin/visas', [AdminVisaController::class, 'index']);
Route::post('/admin/visas', [AdminVisaController::class, 'store']);
Route::get('/admin/visas/{id}', [AdminVisaController::class, 'show']);
Route::put('/admin/visas/{id}', [AdminVisaController::class, 'update']);
Route::delete('/admin/visas/{id}', [AdminVisaController::class, 'destroy']);
```
