# Plan: Replace Tags with Category Values in Hotel Cards

## Goal
Replace the current raw tag badges in hotel cards with up to 3 category value badges derived from the hotel's `category_assignments` data. Apply to both the index page and landing page cards.

---

## Current State

### Tags in Index Page (`pages/hotels/index.tsx`, lines 291-306)
- Renders `hotel.tags` as raw `tagId` strings in a plain muted `div` grid
- Tags are NOT localized — displayed as raw slug strings like "luxury"
- The `tags` field is generated backend from `category_key` (a single legacy field)

### Landing Page (`components/sections/landing/HotelsSection.tsx`)
- Cards and grid styles currently do NOT show tags
- Only show stars + rating, location, name, and amenities

### Category System
- Hotels have `category_assignments: Record<string, string>` where keys are type keys (e.g., "service", "type_chambres") and values are value keys (e.g., "thalasso_spa", "chambre_double")
- `useCategoryTypesPublic('hotels')` returns `PublicCategoryType[]` with nested `values` containing localized `name: { en, fr, ar }`
- Already fetched on the index page via `useCategoryTypesPublic('hotels')` (line 51)

## Implementation Plan

### Step 1: Add utility function to `categoryLabels.ts`
**File:** `resources/js/lib/categoryLabels.ts`

Add a function that resolves category value labels from a hotel's assignments:

```ts
export function getHotelCategoryLabels(
    assignments: Record<string, string> | undefined,
    categoryTypes: Array<{ key: string; values: Array<{ key: string; name: Record<string, string> }> }>,
    lang: string,
    maxCount = 3,
): string[] {
    if (!assignments) return [];
    const labels: string[] = [];
    for (const catType of categoryTypes) {
        if (labels.length >= maxCount) break;
        const valueKey = assignments[catType.key];
        if (!valueKey) continue;
        const value = catType.values.find((v) => v.key === valueKey);
        if (value) {
            labels.push(value.name[lang] || value.name.en || valueKey);
        }
    }
    return labels;
}
```

{(() => {
