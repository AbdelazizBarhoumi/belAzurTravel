# Fix: Missing DialogTitle in mobile sidebar

## Problem

Radix UI's `DialogContent` (wrapped as `SheetContent`) requires a `DialogTitle` for screen reader accessibility. The mobile sidebar in `sidebar.tsx` uses `SheetContent` without providing one, causing the console warning.

## Root Cause

- **File:** `resources/js/components/ui/sidebar.tsx` (lines 156-170)
- `SheetContent` renders without a `SheetTitle` child
- `SheetTitle` is already exported from `sheet.tsx` but not imported in `sidebar.tsx`

## Fix (2 edits in 1 file)

### Edit 1 — Import `SheetTitle` (line 10)

```tsx
// Before:
import { Sheet, SheetContent } from "@/components/ui/sheet";

// After:
import { Sheet, SheetContent, SheetTitle } from "@/components/ui/sheet";
```

### Edit 2 — Add visually hidden title (inside `<SheetContent>`, before the `<div>`)

```tsx
<SheetTitle className="sr-only">Sidebar</SheetTitle>
```

This provides a meaningful accessible name ("Sidebar") while remaining visually hidden via the `sr-only` Tailwind utility.

## Files to Modify

| File | Change |
|------|--------|
| `resources/js/components/ui/sidebar.tsx` | Import `SheetTitle`, add `<SheetTitle className="sr-only">Sidebar</SheetTitle>` as first child of `<SheetContent>` |

No changes needed in `sheet.tsx` — it already exports `SheetTitle`.
