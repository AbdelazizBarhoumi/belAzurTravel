# Ensure Upload Directories Exist Before File Storage

## Problem
On production, uploads appear to succeed (no error) but the folders and images don't exist on disk. Laravel's `->store()` relies on Flysystem to auto-create directories, but on some server configurations (restricted permissions, missing parent dirs) this silently fails. No app-level code calls `File::ensureDirectoryExists()` before any upload.
