# Fix: `C.filter is not a function` Runtime Error

## Root Cause

The `C.filter is not a function` error means `.filter()` is being called on a non-array value (likely `undefined`, `null`, or an object). This happens in multiple locations because the codebase assumes React Query `data` is always an array, but:

1. **`data` defaults only cover `undefined`**, not `null` or objects — `const { data: x = [] } = useQuery(...)` only applies `= []` when `data === undefined`
2. **API responses are sometimes wrapped** in `{ data: [...] }` and sometimes bare arrays, creating inconsistency
3. **No `Array.isArray` guards** before `.filter()` calls

### Most Likely Crash Site

**`useCategories` select callback** (`resources/js/hooks/usePublicData.ts:318`) — called on **every page** via Navbar. The `select` function calls `categories.filter(...)` directly without an `Array.isArray` guard. If the category cache or API returns non-array data, this crashes immediately.

Secondary suspects: all listing pages (tours, deals, cars, events, etc.) and Navbar's `navSettings.header.filter()`.

---

## Plan

### 1. Add `Array.isArray` guards in `usePublicData.ts` hooks

**File**: `resources/js/hooks/usePublicData.ts`

- **`useCategories` (line 313-321)**: Wrap `select` callback to guard against non-array input:
  ```ts
  select: (categories) => {
      if (!Array.isArray(categories)) return [];
      if (!normalizedType) return categories;
      return categories.filter(...);
  },
  ```

- **`useCategoryTypesPublic` (line 342-353)**: Add a `select` callback to normalize the result:
  ```ts
  select: (data) => Array.isArray(data) ? data : [],
  ```

### 2. Add `Array.isArray` guards in all listing page `useMemo` calls

**Files** (each has a `useMemo` calling `.filter()`):
- `resources/js/pages/tours/index.tsx:87-114`
- `resources/js/pages/deals/index.tsx:74-94`
- `resources/js/pages/cars/index.tsx:112-160`
- `resources/js/pages/events/index.tsx:96-120`
- `resources/js/pages/travels/index.tsx:88-122`
- `resources/js/pages/flights/index.tsx:84-155`
- `resources/js/pages/promos/index.tsx:39-55`
- `resources/js/pages/partners/index.tsx:87-98`
- `resources/js/components/sections/blog/BlogListing.tsx:84-106`

Change pattern from:
```ts
useMemo(() => items.filter(...), [items, ...])
```
To:
```ts
useMemo(() => (Array.isArray(items) ? items.filter(...) : []), [items, ...])
```

### 3. Guard Navbar `navSettings.header`

**File**: `resources/js/components/layout/Navbar.tsx:606-611`

Add shape validation before the `.filter()` chain:
```ts
const headerEntries = Array.isArray(navSettings.header) ? navSettings.header : [];
const enabled = headerEntries.filter((h) => h.enabled && getPage(h.pageKey));
```

### 4. Guard `AdminGallery` images state

**File**: `resources/js/pages/admin/AdminGallery.tsx:172-175`

Add an `Array.isArray` check when setting gallery data:
```ts
const data = await fetchGallery();
setImages(Array.isArray(data) ? data : []);
```

### 5. Make `listAdminEntities` return `[]` for non-array responses

**File**: `resources/js/api/admin.api.ts:36`

Change the fallback from returning the raw `res` to returning an empty array:
```ts
return Array.isArray(res) ? res as T[] : [];
```
