# Add Hero Carousel + Landing Section to Visa

## Summary
1. Add hero images manager to the Visa admin page (like hotels, tours, etc.)
2. Create a VisaSection landing page component (like HotelsSection, ToursSection)
3. Register VisaSection in the landing sections system

---

## Changes

### 1. AdminVisas.tsx — Add Hero Images Section
**File:** `resources/js/pages/admin/AdminVisas.tsx`

Add imports: `useEffect`, `useCallback`, `HeroImagesManager`, `useSiteSettings`, `apiFetch`, `PageHeroSlide`, `ImageIcon`, `Save`, `Loader2`

Add state + sync + save:
- `const { settings: siteSettings } = useSiteSettings();`
- `heroSlides`, `heroInterval`, `isHeroSaving` state
- `useEffect` to sync from `siteSettings.content?.page_heroes?.visas`
- `saveHeroImages` callback (PUT to `/api/site-settings`)

Add JSX block before the entity table inside `<AdminLayout>`:
- Card with `HeroImagesManager pageKey="visas"`
- Save button

### 2. Create VisaSection Landing Component
**New file:** `resources/js/components/sections/landing/VisaSection.tsx`

Follow ToursSection pattern:
- Props: `{ config: LandingSectionConfig }`
- Fetch data via new `useVisas()` hook
- Map visa items: `id`, `title` (name), `price`, `meta` (processing), `image` (flag emoji), `href` (`/visa`)
- Switch on `config.style`: carousel → `HorizontalDeals`, cards → 3 items, grid → 6 items

### 3. Create useVisas Hook
**File:** `resources/js/hooks/usePublicData.ts`

Add `useVisas()` function following the same pattern as `useTours()`:
- Fetches from `GET /api/visas`
- Returns visa data with `id`, `code`, `name`, `flag`, `processing`, `price`

### 4. Register in Landing Sections System
**File:** `resources/js/lib/landingSections.ts`
- Add `visas: { labelKey: 'admin.section.visas', styles: ['carousel', 'cards', 'grid'] }` to `LANDING_SECTION_META`
- Add `'visas'` to `LANDING_SECTION_ORDER`

**File:** `resources/js/components/sections/LandingSections.tsx`
- Import `VisaSection`
- Add `visas: VisaSection` to `SECTION_COMPONENTS`

### 5. Add Translation Key
**File:** `resources/js/i18n/translations.ts`
- Add `admin.section.visas: { fr: 'Visa', en: 'Visas', ar: 'التأشيرات' }`
