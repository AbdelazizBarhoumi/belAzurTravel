# Plan: Fix Category Type Assignments Not Loading in Admin Edit

## Problem

When editing an entity (hotel, tour, etc.) in the admin, category type assignments appear as "select" (default) instead of showing the saved value. The data is saved correctly but not loaded back.

## Root Cause

The admin controllers don't load the `categoryAssignments` relation when fetching entities. The `adminPayload` method checks `$item->relationLoaded('categoryAssignments')` which returns false, so `$categoryAssignments` stays empty.

## Fix

Add `->with(['categoryAssignments.categoryType', 'categoryAssignments.categoryValue'])` to all admin controller index methods.
