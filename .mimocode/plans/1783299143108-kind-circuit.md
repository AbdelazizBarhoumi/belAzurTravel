## Gap 1: Hero Carousel Images (MISSING)
**Location:** `site_settings.content.page_heroes.{pageKey}`

Each page has a hero carousel. Structure:
```json
"page_heroes": {
  "home": {
    "images": [
      { "url": "https://...", "title": {"en":"...", "fr":"...", "ar":"..."}, "subtitle": {"en":"...", "fr":"...", "ar":"..."} }
    ],
    "interval": 6000
  }
}
```

**Pages that need hero images:** `home`, `hotels`, `tours`, `travels`, `destinations`, `cars`, `flights`, `events`, `deals`, `blog`

**Fix:** Add `page_heroes` to the site settings content in `seedSiteSettings()`. Each page gets 2-3 hero slides with Unsplash images, trilingual titles/subtitles, and interval.

## Gap 4: Category Assignments — Only `pricing_type` Assigned (PARTIAL)
The `assignCategory()` method hardcodes `pricing_type` as the only category type. This means:
- Hotels: ✅ assigned (pricing_type: all-inclusive, half-board, etc.)
- Tours: ✅ assigned (pricing_type: per-person, per-group)
- Travels: ✅ assigned (pricing_type: per-person, per-group)
- Cars: ❌ NOT assigned (transmission_type: automatic/manual)
- Events: ❌ NOT assigned (event_type: cultural/festival/sport)
- Deals: ❌ NOT assigned (deal_type: flash-sale/seasonal/bundle)
- Blog: ❌ NOT assigned (blog_category: travel-tips/destination-guide/news)
- Destinations: ❌ NOT assigned (region: north-africa/middle-east/europe/asia/africa)

**Fix:** Change `assignCategory()` to accept a generic `categoryTypeKey` parameter instead of hardcoding `pricing_type`. Update all callers to pass the correct key.

---

## Gap 5: Filter Boolean Fields All `false` (MISSING)
All filter booleans default to `false` because the seeder doesn't set them.

### Hotels (20 filter fields, all false):
- `htel_recommande` → true for top-rated hotels (La Badira, Iberostar, Dubai Marina, etc.)
- `tarifs_promo` → true for budget hotels (Occidental)
- `enfant_gratuit` → true for family hotels
- `thalasso_spa` → true for spa hotels
- `famille` → true for family resorts
- `petit_dejeuner`, `demi_pension`, `pension_complete` → match hotel packages
- etc.

### Tours (10 filter fields, all false):
- `tunisia` → true for Tunisia tours (Sud Tunisie, Djerba, Tunis-Carthage)
- `djerba` → true for Djerba tours
- `nord_tunisien` → true for northern Tunisia tours
- `famille` → true for family-friendly tours
- etc.

### Travels (6 filter fields, all false):
- `istanbul` → true for Istanbul travels
- `asie` → true for Asia travels (Bali, KL, Bangkok)
- `europe` → true for Europe travels (Paris)
- `afrique_nord` → true for North Africa (Morocco, Tunisia)
- `tranquille` → true for relaxed trips
- `jeune` → true for adventure/young traveler trips

**Fix:** Set appropriate filter booleans in each hotel/tour/travel seed data array.
